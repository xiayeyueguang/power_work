线性工程量 ↔ 电信号

公式：实际值 = 量程下限 + (测量信号 − 信号下限) × (量程上限 − 量程下限) / (信号上限 − 信号下限)。适用于 4–20 mA、0–10 V、1–5 V 等任意线性区间。

进制转换（二 / 八 / 十 / 十六）

在任意一个框中输入整数，其余三框即时联动。十六进制可带 0x 前缀，二进制可带 0b 前缀，八进制可带 0o 前缀；各框均支持前导 ±（空框表示未输入）。中间态无法解析时仅提示，不覆盖其它框。

PT100 三线制（简易说明）

三线制意在抵消引线电阻：两线接同一端子侧与仪表构成桥路/恒流回路，使两根引线压降相互抵消。若三根线不等长或接触电阻不一致，仍会有残余误差；精密场合用四线制。本工具按敏感元件本体电阻计算，不含引线误差。

Cu50 采用 −50～150℃ 常用二次多项式（与分度表略有偏差）；PT100/PT1000 为 IEC 60751 Callendar–Van Dusen，范围约 −200～850℃（Cu50 以外推为主）。

热电偶（ITS-90 · 可选冷端补偿）

补偿关系（同一分度号）：测得 mV ≈ E(热端)−E(冷端)。故 mV→℃ 时先算 E₀ = 测得 + E(冷端)；℃→mV 时给出表计端 mV = E(热端)−E(冷端)。表头已内部补偿时，冷端填 0，并把读数当 0℃ 参考。

其它实用建议

  • 模拟量：注意 PLC/DCS 中工程量是否为「工程单位」还是「整型码值」（如 0–27648）。
  • 4–20 mA：断线/欠量程常 <4 mA，可做仪表与程序报警。
  • 热电阻：自热与恒流大小有关；高速采样注意滤波与导线电容。
  • 热电偶：延长线与补偿导线分度号须匹配；电磁环境考虑屏蔽与接地。
  • 标定：关键回路建议用标准源/标准电阻箱记录一点以上校核。

PLC 模块选型步骤与方法

  1. 第一步：梳理 IO 信号清单，明确现场接口参数。先依据控制原理图、工艺要求整理完整 IO 清单，统计 DI、DQ（数字量输出）、AI、AQ 实际点数。同时明确关键电气参数：数字量——工作电压、漏型 / 源型、晶体管 / 继电器输出类型、负载特性；模拟量——信号制式（0–10 V、4–20 mA）、热电阻 RTD、热电偶 TC，是否需要隔离、防爆、本安、户外宽温规格；单独特殊信号——高速脉冲输入（编码器）、运动控制、凸轮定位、安全 IO，不占用普通 IO 通道，单独预留专用模块或安全 PLC，不混算普通点数。
  2. 第二步：确定
    系统架构

    怎么确定 PLC 系统架构（新手也能直接套用的通用思路）

    一、先搞懂 3 种基础架构类型

    集中式架构　所有 IO、所有控制柜全部放中控室 / 主柜，现场只留传感器、按钮、电机。

    分布式（远程 IO）架构　主 CPU 在中控，现场每个工段 / 每个设备单独放远程 IO 从站，就近接信号。

    冗余高可靠架构　CPU 冗余、电源冗余、网络环网冗余，停机损失大的关键生产线用。

    二、决定架构的 6 个核心判断依据（按这个顺序一步步定）

    1. 看设备分布距离　设备集中、全部在一个车间小范围：选集中式。设备分散、跨车间、长流水线、现场点位离中控超过 50～100 米：必须分布式远程 IO。原因：省电缆、减少长线干扰、降低布线成本。
    2. 看工艺分段 & 工段独立性　整个工艺是一体联动、不能拆分：集中式。工艺可分成上料、烘干、包装、输送独立工段：分布式，一段一个远程从站。好处：分段调试、分段检修，一段故障不影响整套架构。
    3. 看干扰与信号类型　有大量变频、伺服、高频动力线、模拟量仪表：优先分布式，模拟量就近进远程 IO，减少长距离走线干扰。普通风机水泵、开关量多、无精密模拟量：集中式够用。
    4. 看停机损失 & 可靠性要求　普通流水线、非标设备、停机影响小：普通单 CPU 架构。化工、能源、热力、水厂、关键产线，不能随便停机：上 CPU 冗余 + 电源冗余 + 工业环网高可靠架构。
    5. 看后期扩容 & 改造需求　以后可能加设备、扩产线：直接上分布式总线架构（Profinet、Modbus-RTU/TCP、EtherCAT），后期直接加从站就行，不用动主柜。一次性小设备、以后不改造：集中式省钱省事。
    6. 看施工成本 & 布线条件　现场布线困难、桥架远、拉电缆造价高：分布式远程 IO，就近接线，大幅省电缆人工。柜间距离近、布线方便：集中式更简单好维护。

    三、快速选型对照表（直接对号入座）

    项目场景推荐架构
    单台小设备、小型控制柜、点位少、距离近集中式
    长流水线、多工位、跨区域、点位分散分布式远程 IO
    化工、水厂、电厂、关键工艺、不允许停机冗余架构（CPU + 电源 + 环网）
    模拟量多、变频伺服多、怕干扰分布式就近采集
    后期要扩产、加设备分布式总线架构

    四、定架构的标准步骤（以后做项目直接按流程走）

    1. 画出车间设备布局图、工艺分段图
    2. 量各工段到中控的距离
    3. 统计每段 IO 点数、模拟量 / 高速信号数量
    4. 评估停机影响等级（普通 / 关键 / 不能停）
    5. 评估后期是否扩容
    6. 最终确定：集中式 / 分布式 / 冗余架构
    7. 再划分：主 CPU 机架 + 各个远程从站位置、通讯网络拓扑
    ，划分控制布局。选定整体控制架构：集中式、远程分布式、冗余架构。按工艺工段、配电区域、现场距离，划分本地机架 + 远程 IO 从站；规划网络拓扑、通讯方式，涉及冗余 CPU、冗余电源、环网、上位机 HMI/SCADA 时，初期一并定型；提前预留扩展空间，避免后期点数够用，但系统架构无法扩容、改造返工。
  3. 第三步：按信号类型匹配 IO 模块规格。根据信号类型逐一匹配模块系列与硬件规格：数字量模块——核对工作电压、单通道承载电流、公共端分组方式；感性负载选继电器输出，高频通断选晶体管输出；模拟量模块——确认分辨率、信号量程、2/3/4 线制接线、滤波及故障诊断功能；优化排布——同类信号尽量集中在同一模块，减少单点占用整模块造成浪费；预留余量——整体预留 10%～20% 备用通道，同时核对工作温度、防腐涂层、行业认证（CE、防爆、船级等）。
  4. 第四步：核算电源与背板负载容量。统计 PLC 机架内所有模块背板总线电流，严格匹配电源模块额定容量，考虑高温降容；单独核算外部 24 V 负载：变送器、电磁阀、阀岛、传感器供电，不和机架电源混算；实用原则：大功率电磁阀、感性负载，优先加中间继电器 / 固态继电器 + 独立外部电源，减少 PLC 模块触点负荷与发热。
  5. 第五步：清单汇总 + 官方选型工具交叉校核。按整理好的 IO 点数汇总统计，锁定 DI/DQ/AI/AQ 总数量；利用品牌官方选型工具（西门子 TIA 选型器、三菱 / 施耐德选型样本等），匹配具体模块型号、订货号、基座、端子、固件版本；生成 BOM 清单初稿，正式项目必须对照最新厂家样本校对，避免型号停产、版本不兼容。

实用技巧速记：① 先冻结 IO 清单版本再定模块与从站划分，避免边做边加导致机架与网络推倒重来。② AI/AO 对接地、屏蔽、共模干扰敏感，宁可用对通道类型与线缆规格，勿为凑满通道牺牲裕量。③ 柜内分区布线：动力与信号分层或分槽，模拟量靠近等电位与屏蔽汇流。④ 本页右侧西门子模块为课用估算；其它品牌按同五步换用各厂选型器与当期型录。

电气元件选型步骤与方法

一句话：先弄清要控谁、怎么控、用什么电，再定强电启停方式 + 弱电/PLC 怎么配合，然后在本页点对象表做粗算，再补按钮、端子、柜内线，最后合成材料表并审核。下面五步按顺序做即可。

  1. 第一步：读图，把「控制要求」对齐。
    • 从工艺图、P&ID、控制说明里拉出一份被控对象清单：每台设备要测什么、控什么（例如启停、调速、阀门、联锁、报警）。
    • 顺手记下工况与环境：连续/间歇、粉尘、腐蚀、温度等，后面选外壳、器件等级用得到。
    • 确认配电与控制电源：例如柜顶是否 AC380V 进线、柜内二次是 AC220V 还是 DC24V 等；图纸上没写清的标问号，向工艺或电气专业问清楚再往下做。
  2. 第二步：分清「一次」和「二次」，定控制策略。（策略不定，后面断路器、PLC 都无从谈起。）
    • 一次侧（动力主回路）：电机/负载的功率、电流、台数；每台打算直启、星三角、软启还是变频——这直接决定主开关、接触器、变频器等规格与数量。
    • 二次侧（控制与信号）：用 PLC 还是继电器逻辑、有哪些传感器/仪表信号；急停、安全门等是否要独立于 PLC 的安全回路——这决定辅助继电器、安全继电器、I/O 等。
  3. 第三步：在本页做「主回路」粗算与汇总。
    • 在下方「被控对象与回路」里：勾选对象 → 选负载类型与控制方式 → 填台数；选好低压品牌以及（若有）变频器/软启品牌。
    • 点「汇总选型」，得到断路器、接触器、热继、变频/软启等的合计划数 + 课用示例型号（用于教学或现场快速对量，不是最终施工图）。
    • 算电流两种口径：多回路、要快估时可用课内近似 I ≈ P×2（kW→A，三相 380V 经验式）；单台要细一点时，用本页「电气元件选型」按 kW、η、cos φ 算 Ib，并粗选外线/柜内电缆截面及主器件。
    • 还要深化：短路分断能力、上下级保护配合、整定值等，必须用厂家样本 + 设计规范另算，本页不代替。
  4. 第四步：辅件与柜内配套（按钮、端子、线）。
    • 对照原理图、端子图、线号表，在页面下方三块整行通栏区域依次选：按钮与指示灯、接线端子、柜内电缆。
    • 按触点形式、颜色、线径、回路类型选用即可；完整订货号仍须用厂家样本补后缀、核对版本。
  5. 第五步：合成 BOM，留人审核。
    • 把主器件 + 辅件汇总成一份材料表（BOM），逐项过：额定值、认证、安装类别、紧固扭矩、柜内安装位置是否都合理。
    • 重要工程或涉安项目，应由具备资质的设计/审核人员按国标、地方法规与合同要求定稿。

本页能做什么：把「工艺/控制意图 → 对象表 → 主器件 → 辅件」串成一条线，方便教学与现场粗查。本页不能替代：正式设计软件、厂家选型器、以及强制性标准条文——定货与施工以前务必再核对。

电流回路与电压回路（二次）

与主回路分槽或分层敷设；线号与端子分区按项目规定。详细定义见下表备注列。

什么是「电流回路」？

CT 二次至表计/保护/变送器（常见 5 A / 1 A），运行中严禁开路；多表并联须按负荷 VA 与准确级核算。

什么是「电压回路」？

PT 二次或低压母线直采至表计/保护；首端须保护器件，与电流回路分开布线。

MODBUS RTU 通讯要点

物理层：RS485 半双工，A/B 按图纸接（勿与邻设备反接）；总线物理两端各加 120 Ω 终端电阻（长线、高速或不稳定时尤须）；推荐屏蔽双绞线，屏蔽层单端接地；参考地/SG 按设备手册。

通讯参数：站地址 1～247（0 为广播，从站不应答）· 波特率 · 数据格式（如 9600,E,8,1）· 读/写 · PDU 地址指针。

帧结构：设备地址 + 功能码 + 数据 + CRC16（低字节在前）；帧间间隔 ≥ 3.5 字符时间（T3.5）。

功能码 01 — 读线圈（0x 区）

案例：1 号站，从 PDU 0（文档 00001）读 8 点线圈；返回 1 字节位图 0x55（bit0=1, bit1=0, bit2=1… 即 ON/OFF 交替）。

主站发送
发送：01 01 00 00 00 08 3D CC
从站响应
返回：01 01 01 55 91 B7

解析：字节数 = ⌈线圈数÷8⌉；第 k 点 = 数据字节[⌊k/8⌋] 的 bit(k mod 8)，低位在前。

功能码 02 — 读离散输入（1x 区）

案例：1 号站，从 PDU 2（文档 10003）读 4 点 DI；返回 0x0A（二进制 1010 → 点0=0, 点1=1, 点2=0, 点3=1）。

主站发送
发送：01 02 00 02 00 04 D8 09
从站响应
返回：01 02 01 0A 21 8F

帧结构与功能码 01 相同；离散输入区只读，无写功能码。

功能码 16 — 写多个保持寄存器（4x 区）

案例：1 号站，从 PDU 1 起写 2 字：Reg1=1(0x0001)、Reg2=2(0x0002)。

从站响应

MODBUS 从站扫描工具

对指定站号范围逐站发送读保持寄存器（FC03），有正常或异常回应即视为在线。默认读地址 0、数量 1；部分设备地址 0 无数据时可能漏扫，可改用通讯测试指定地址复核。

MODBUS 从站通讯测试工具
